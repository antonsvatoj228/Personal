# Інструменти перевірки прайс-листа Phoenix Bukovel

Скрипти незалежно відтворюють логіку ціноутворення з Excel-файлу і звіряють її з тим,
що реально записано в комірках. Використані для аудиту `../PHOENIX_PRICELIST_AUDIT.md`.

## Запуск

```bash
pip install openpyxl
cp "<шлях до прайсу>.xlsx" price.xlsx   # скрипти читають ./price.xlsx
python3 pricing_model.py      # звірка моделі з 144 комірками листа «Прайс»
python3 sweep_coverage.py     # покриття прайс-листів / тарифів, діра «Люкс 3 ос.»
python3 compare_engines.py    # розбіжності між Прайс / Калькулятор / Контроль
```

## Що робить кожен скрипт

- **`pricing_model.py`** — читає всі параметри з листа «Керування прайсом» і «Довідник
  категорій», реалізує дві формули: `price_sheet()` (логіка листа «Прайс») і `price_calc()`
  (логіка листа «Калькулятор»). При прямому запуску звіряє власний розрахунок із
  закешованими значеннями листа «Прайс».
- **`sweep_coverage.py`** — повний перебір прайс-листів × тарифів × типів дня × акцій ×
  категорій × кількості гостей: показує розбіжності Прайс/Калькулятор, значення, які
  Калькулятор досі видає для «Апартаменти Люкс 25 м²» × 3 гостей, звірку «Матриці категорій»
  з «Прайсом» і перелік комбінацій, що дають порожню сітку.
- **`compare_engines.py`** — додає третій двигун `price_control()` (логіка листа «Контроль і
  порівняння») і рахує, у скількох відсотках сценаріїв три листи дають різні цифри.
